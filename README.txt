THHG Indoor Scorer PWA

Upload ALL files in this folder together to an HTTPS website, keeping their filenames and paths unchanged. Open index.html via the hosted URL.

iPhone: Safari > Share > Add to Home Screen.
Android: Chrome > menu > Install app / Add to Home screen.

Open the app online once before using it offline. Test airplane mode and score persistence before a match. Scores are stored separately per device and per website address; opening this hosted version will not automatically import scores from previous downloaded HTML files. Export CSV before switching. Browser data clearing or uninstalling can remove scores.

To publish an update, increment CACHE in service-worker.js, upload all files, then reopen the app online.
